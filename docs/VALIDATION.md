# Проверка версии 2.2

Дата: **29 октября 2026 года**. Источники характеристик в каталоге сверены 28 октября; при этой проверке их содержимое повторно не запрашивалось.

## Автоматические тесты

Полный прогон: **100 passed in 67.49s**, без пропусков. Включены прежние проверки версии 2.1 и 17 новых проверок качества, графа, уточнений и интерфейса.

Проверены:

- Исходные позитивный, конфликтный, неполный и пустой сценарии; границы бюджета, BIOS и мощности.
- Совместимость сокетов, DDR, форм-факторов, числа модулей, габаритов и разъёмов.
- Реальные строковые BIOS: точное совпадение, неизвестная версия и явная неподдержка; без лексикографического сравнения.
- Отсутствие подмены TDP пиковой мощностью; использование прямого подтверждения Noctua для CPU.
- Неизвестные значения и известный ноль; отсутствие ложной потребности в неиспользуемом типе разъёма.
- Режим встроенной графики, точное крепление M.2, толщина GPU, зазор RAM, порог рекомендации GPU и длина БП.
- Пользовательские цены отдельно от производителя, бюджет при неизвестных ценах, импорт и экспорт JSON.
- Поиск полной сборки и исправлений; сравнение с исчерпывающим перебором ограниченной области; минимум двух замен; фиксация компонентов; недостижимый бюджет; остановка по лимиту; отдельный критерий числа ядер.
- Источники каждого реального утверждения и чтение фактов из изменённого OWL.
- Пять SPARQL-запросов.
- HermiT: согласованность, новые классы компонентов и сборок, отказ при противоречащих типах, отсутствие ложного VerifiedBuild у неполного/конфликтного варианта.
- Экспорт OWL с исходными фактами и пользовательскими ценами; исходная база при этом не меняется.
- Streamlit: сценарии, подбор и применение замены, реальные модели, строковый BIOS, автоподбор и применение конфигурации.
- SQLite: сохранение и обновление именованных сборок, повторное открытие базы, обратимый архив, нулевая и неизвестная цена, атомарный отказ при неверных ценах. Повреждённая база и база более новой версии не заменяются.
- Восстановление черновика в новом сеансе и сохранение исходного повреждённого черновика без автоматической перезаписи; сохранение пользовательских цен между каталогами.
- Библиотека в интерфейсе: создание, открытие, обновление, сравнение, архивирование и восстановление.
- HTML-отчёт: состав, объяснения, неполные цены, источники и экранирование пользовательского текста.
- SHACL: исходный каталог и неполная сборка проходят; отсутствие обязательного сокета CPU, отрицательная мощность БП и отсутствие URL у источника утверждения производителя обнаруживаются.
- Происхождение: учитываются записи для отдельных поддерживаемых CPU; удаление одной такой записи уменьшает покрытие. Будущие, старые и неверные даты рассматриваются отдельно от соответствия SHACL.
- Граф: фактические входящие и исходящие связи, переключение значений и происхождения, два перехода без анонимных конструкций OWL, ограничение узлов, согласованный экспорт Turtle, отказ для неизвестного ID.
- Уточнения: неизвестные BIOS, пиковые мощности, габариты и цены; объединение повторов, пустая сборка, отсутствие запросов цен без бюджета и отделение подтверждённых конфликтов.
- Интерфейс 2.2: запуск аудита, список уточнений и скачивание, смена типа исследуемого объекта, глубины и отображения значений.

Среда: Windows, Python 3.12, Streamlit 1.66.1, Owlready2 0.51, pySHACL 0.40.1, RDFLib 7.6.0, pytest 9.2.0, установленная Java 8; HermiT с лимитом 512 МБ.

## Сценарная оценка

Повторяется командой `python -m pc_ontology.evaluation`.

Получено **20/20 ожидаемых исходов** на специально сконструированных сценариях. Упрощённая проверка только сокета дала 5/20 совпадений на том же наборе.

| Ожидаемый исход | Подтверждено | Конфликт | Неизвестно |
|---|---:|---:|---:|
| Подтверждено | 2 | 0 | 0 |
| Конфликт | 0 | 11 | 0 |
| Неизвестно | 0 | 0 | 7 |

Это проверка поведения на заданных случаях, **не независимая оценка точности для реального рынка**. Разметка отражает ограничения и объём знаний прототипа.

Поиск учебной сборки при бюджете 80 000 завершён: минимум 52 000, 43 посещённых узла в контрольном запуске с одним возвращаемым вариантом. Исправление двух конфликтов при фиксации остальных деталей завершено двумя заменами, 37 узлов. Числа относятся к этому каталогу и выбранным параметрам, не являются общим обещанием производительности.

## Браузер и поставка

Аудит версии 2.2: **соответствие SHACL — да, 0 нарушений**. В браузере отдельно проверен снимок текущей совместимой сборки вместе с каталогом — также 0 нарушений. Для 32 реальных компонентов найдены записи происхождения для **225 из 225** учитываемых значений; у 45 источников корректные недавние даты, поводов для пересмотра по порогу 180 дней нет. Это наличие записей в базе, а не повторное подтверждение содержимого сайтов. Сохранены `docs/quality/catalog-quality.json` и `docs/quality/shacl-report.ttl`.

Сервер Streamlit работает на loopback; проверка здоровья вернула HTTP 200. В браузере проверены поиск и расширенная онтология, а для версии 2.1 — сохранение и обновление примерной сборки через интерфейс, сохранение активной вкладки после действия, библиотека и читаемость отчёта внутри приложения. Включённый iframe поддерживает системный диалог печати; физическая печать не запускалась. В версии 2.2 проверены запуск аудита и его показатели, смена исследуемого CPU с обновлением графа на AM5/DDR5 и входящими связями поддержки кулеров; основная сборка оставлена на исходном совместимом учебном примере.

Снимки: `preview-v2.png` (поиск), `preview-v2.1.png` (библиотека), `report-preview-v2.1.png` (отчёт), `quality-preview-v2.2.png` (аудит), `graph-preview-v2.2.png` (фактические связи). Для демонстрации в локальной библиотеке оставлена одна примерная сборка. При сборке дистрибутива проверяется отсутствие папки пользовательских данных и SQLite-файлов в ZIP.

Пакет включает исходники, OWL-каталог, JSON/OWL-примеры, официальные источники, методическое описание и результаты оценки. Пользовательская библиотека хранится отдельно в `data/contour.sqlite3` и не включается в ZIP. Скрипты запуска Windows сохранены. Установка на отдельном чистом компьютере не проверялась; первая установка требует интернета.

Проверка реальных моделей ограничена опубликованными фактами и условиями. Пиковая мощность, часть механических ограничений и фактическая прошивка экземпляра остаются неизвестными. Такие варианты явно обозначаются условными, а не полностью подтверждёнными.
