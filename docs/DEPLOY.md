# Публичная демонстрация

Публикуйте `cloud_app.py` на Streamlit Community Cloud с Python 3.12.
`requirements.txt` устанавливает Python-зависимости, `packages.txt` — Java для HermiT и инструменты сборки.

В публичном режиме у каждого сеанса собственная база SQLite в памяти. Она не читает локальную папку `data`, не разделяется между посетителями и не сохраняется после завершения сеанса. Для длительного хранения скачайте JSON сборки. Вход в приложение посетителям не требуется; персональные аккаунты и постоянная облачная библиотека пока не реализованы.

Настольный запуск через `START.bat` продолжает использовать `app.py` и локальную SQLite. Данные из `data`, окружение `.venv` и секреты не включаются в Git.

## Размещение

1. Загрузить исходники в репозиторий GitHub.
2. В Streamlit Community Cloud выбрать Create app, репозиторий, ветку `main` и файл `cloud_app.py`.
3. В Advanced settings выбрать Python 3.12. Секреты для этого проекта не нужны.
4. После запуска проверить конфигуратор, конфликт памяти, экспорт JSON, вкладку качества данных и логический вывод.
5. В настройках доступа выбрать публичный просмотр и отправить полученный адрес посетителям.

Бесплатный хостинг имеет ограничения ресурсов и может приостанавливать неактивные приложения; постоянная доступность без задержек не гарантируется. При обновлении кода приложение перезапускается, сеансовые сохранения теряются.

Документация: https://docs.streamlit.io/deploy/streamlit-community-cloud/deploy-your-app/deploy
